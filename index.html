Never Lose Track of Your Warranties

Information Stored

  • Product names
  • Purchase dates
  • Warranty durations
  • Warranty expiration dates
  • Store names
  • Serial numbers
  • Receipt numbers
  • Product descriptions
  • Additional notes
  • Product images
  • Receipt images

How Information Is Used

The information stored in Trezuno is used only for the following purposes:

  • Calculating warranty expiration dates
  • Sending local reminders (if enabled)
  • Organizing products in the list
  • Providing an enhanced user experience

Local Data Storage

All data in Trezuno is stored locally on your device:

  • Data is not transmitted to any external servers
  • Data is not stored in the cloud
  • Data is not shared with third parties
  • Users can delete all data at any time

Product and Receipt Images

Users can add product and receipt images:

  • Images are stored locally on the device
  • Images are not uploaded to any servers
  • Users can delete images at any time
  • Images are accessible only within the application

Notifications

Local notifications can be enabled before warranty expiration:

  • Users choose when they want to be reminded (30, 14, 7, or 1 day)
  • No notifications are sent without user consent
  • Notifications can be disabled at any time from settings
  • The application does not use remote notification services

Third-Party Services

Trezuno does not use any third-party services:

  • No advertisements
  • No tracking
  • No analytics
  • No login required
  • No cloud synchronization

Data Retention

Trezuno retains data until the user deletes it:

  • Data remains after application restart
  • All data can be deleted at any time from settings
  • Users are warned before complete data deletion

User Rights

Users have the following rights:

  • Right to access their data
  • Right to correct information
  • Right to delete all data
  • Right to stop processing
  • Right to object to processing
